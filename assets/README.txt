GANTI FOTO WEBSITE DI FOLDER INI

Salin foto dari album Anda ke folder assets dengan nama file berikut:

hero-coffee.jpg    = foto kopi untuk sisi kiri halaman utama
hero-interior.jpg  = foto interior cafe untuk sisi kanan halaman utama
menu-coffee.jpg    = foto Es Kopi Gula Aren
menu-pasta.jpg     = foto Pasta Nusantara
menu-cake.jpg      = foto Pandan Coconut Cake
story-main.jpg     = foto utama bagian Tentang Kami
story-detail.jpg   = foto kecil bagian Tentang Kami
space.jpg          = foto suasana cafe

Format yang disarankan: JPG atau PNG. Jika ingin memakai nama file lain,
ubah nama file pada style.css di bagian background-image.
